# KO Systems

Site institucional e portfólio da KO Systems, desenvolvido com React, TanStack Start, TypeScript, Vite e Tailwind CSS.

## Desenvolvimento local

Requisitos: Node.js 24 ou uma versão LTS compatível e npm.

```sh
npm install
npm run dev
```

O servidor local informa o endereço de acesso no terminal.

## Verificações

```sh
npm test
npm run check:independence
npm run typecheck
npm run lint
npm run build
```

## Marca e conteúdo

Os arquivos de marca ficam em `public/brand`. O conteúdo público usa projetos anonimizados e demonstrações com dados fictícios. Não adicione informações de clientes, endereços de repositórios privados ou credenciais.

## Publicação

O comando `npm run build` gera o artefato de produção. A plataforma de hospedagem e a configuração de DNS são decisões separadas deste repositório.
